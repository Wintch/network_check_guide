# Example --telemetry-domains-file for net_watchdog.py --mode telemetry/all.
#
# One domain per line, '#' starts a comment. This file is ADDED to the
# built-in list in the script (DEFAULT_TELEMETRY_DOMAINS) -- the first
# section below is already in that built-in list, repeated here so this
# file stands on its own as a readable reference/template.
#
# Matching note: the watchdog resolves (A + AAAA) only the names listed here,
# so "conviva.com" does NOT cover "<device-hash>.cws.conviva.com". List
# concrete subdomains you have seen in your own traffic, or run with
# --dns-log <your resolver's query log> to suffix-match every queried name.
#
# Usage:
#   python3 net_watchdog.py --mode telemetry --telemetry-domains-file telemetry_domains.example.txt
